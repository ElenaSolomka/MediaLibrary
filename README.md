# Медиабиблиотека - Микросервисное приложение

Приложение для ведения картотеки фильмов и книг с возможностью связывания их между собой (фильмы, снятые по книгам, и книги, по которым сняты фильмы).

## Архитектура

Решение состоит из 3 независимых микросервисов:

### 1. WebApp (порт 5000)
- **Тип:** ASP.NET Core MVC
- **Назначение:** UI, API Gateway и авторизация
- **Функции:**
  - Cookie Authentication
  - Агрегация данных из микросервисов
  - Админ-панель для CRUD операций
  - Публичные страницы для просмотра фильмов и книг

### 2. MoviesService (порт 5001)
- **Тип:** ASP.NET Core Minimal API
- **Назначение:** Управление данными фильмов
- **База данных:** SQLite (movies.db)
- **API Endpoints:**
  - `GET /api/movies` - список всех фильмов
  - `GET /api/movies/{id}` - один фильм по ID
  - `GET /api/movies/by-book/{bookId}` - фильмы по ID книги
  - `POST /api/movies` - создать фильм
  - `PUT /api/movies/{id}` - обновить фильм
  - `DELETE /api/movies/{id}` - удалить фильм

### 3. BooksService (порт 5002)
- **Тип:** ASP.NET Core Minimal API
- **Назначение:** Управление данными книг
- **База данных:** SQLite (books.db)
- **API Endpoints:**
  - `GET /api/books` - список всех книг
  - `GET /api/books/{id}` - одна книга по ID
  - `GET /api/books/by-movie/{movieId}` - книги по ID фильма
  - `POST /api/books` - создать книгу
  - `PUT /api/books/{id}` - обновить книгу
  - `DELETE /api/books/{id}` - удалить книгу

## Запуск приложения

### Предварительные требования
- .NET 8.0 SDK или выше

### Инструкция по запуску

1. **Откройте три терминала** (командные строки)

2. **Запустите MoviesService:**
   ```bash
   cd MoviesService
   dotnet run
   ```
   Сервис будет доступен по адресу: http://localhost:5001

3. **Запустите BooksService:**
   ```bash
   cd BooksService
   dotnet run
   ```
   Сервис будет доступен по адресу: http://localhost:5002

4. **Запустите WebApp:**
   ```bash
   cd WebApp
   dotnet run
   ```
   Приложение будет доступно по адресу: http://localhost:5000

### Альтернативный способ (Visual Studio)

1. Откройте файл `MediaLibrary.sln` в Visual Studio
2. Настройте запуск нескольких проектов:
   - Правый клик на Solution → Properties → Startup Projects
   - Выберите "Multiple startup projects"
   - Установите Action "Start" для всех трех проектов
3. Нажмите F5 для запуска

## Первый запуск и данные

При первом запуске WebApp автоматически:
- Создает базу данных пользователей (users.db)
- Создает seed-пользователя с правами администратора:
  - **Логин:** admin
  - **Пароль:** admin123
  - **Роль:** Admin

## Демонстрация работы

### 1. Вход в систему
- Перейдите на http://localhost:5000
- Нажмите "Вход"
- Введите логин: `admin`, пароль: `admin123`

### 2. Создание книги
- Перейдите в "Админ-панель" → "Книги"
- Нажмите "Создать книгу"
- Заполните данные книги
- В поле "ID связанных фильмов" можно указать ID фильмов через запятую (если они уже созданы)

### 3. Создание фильма
- Перейдите в "Админ-панель" → "Фильмы"
- Нажмите "Создать фильм"
- Заполните данные фильма
- В поле "ID связанных книг" укажите ID книг через запятую
- URL постера - это просто ссылка на изображение (например, из Wikipedia)

### 4. Просмотр связанных данных
- Откройте страницу книги → увидите список связанных фильмов
- Откройте страницу фильма → увидите список связанных книг

### 5. Создание нового пользователя-админа
- Перейдите в "Админ-панель" → "Пользователи"
- Нажмите "Создать пользователя"
- Заполните данные и выберите роль "Admin"

## Технологии

- **Backend:** ASP.NET Core
- **Frontend:** Bootstrap 5, Razor Views
- **База данных:** SQLite (каждый сервис использует свой файл)
- **Авторизация:** Cookie Authentication
- **Архитектура:** Микросервисы, REST API
- **HTTP-клиент:** IHttpClientFactory

## Структура базы данных

### Users (WebApp)
- Id (int, PK)
- Login (string, unique)
- PasswordHash (string)
- Role (enum: User, Admin)

### Movies (MoviesService)
- Id (int, PK)
- Title, Year, Director, ProductionCompany, MainActors, Description, ImageUrl
- RelatedBookIds (список int, хранится как строка через запятую)

### Books (BooksService)
- Id (int, PK)
- Title, Year, Publisher, PageCount, Annotation
- RelatedMovieIds (список int, хранится как строка через запятую)

## Особенности реализации

- Каждый сервис использует свой собственный файл SQLite
- Сервисы общаются только по HTTP (REST)
- WebApp выступает агрегатором и не хранит данные фильмов и книг
- Пароли хэшируются через PasswordHasher<User>
- Конфигурация через appsettings.json (URL сервисов и строки подключения)
- Автоматическое создание БД при первом запуске (EnsureCreated)
